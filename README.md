## Overview

Steam Achievement Notifier is a desktop overlay application that intercepts Steam achievement events and displays animated, richly themed notification cards with achievement artwork, rarity percentages, and custom sounds — far beyond the minimal Steam default pop-up. It features a community theme repository with live preview, per-rarity sound customization, and a comprehensive settings panel for position, size, and animation style.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Steam Achievement Notifier** delivers the features you need in a clean, intuitive package.

| Feature | Description |
|---------|-------------|
| **Custom Overlay Cards** | Fully skinnable notification cards with position, size, and animation control |
| **Achievement Artwork** | Fetches and displays achievement icons and descriptions from Steam API |
